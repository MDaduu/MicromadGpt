# Simple Tasks App (PHP + MySQL)

تطبيق مهام بسيط (MVP) يدعم:
- تسجيل مستخدم جديد.
- تسجيل الدخول والخروج.
- إضافة مهمة جديدة.
- تحديث حالة المهمة (`new`, `in_progress`, `done`).
- حذف المهمة.
- عرض المهام مع فلترة حسب الحالة.

## المتطلبات
- PHP 8+
- MySQL 5.7+ أو MariaDB
- Apache/Nginx (أو XAMPP/Laragon محليًا)

## هيكلة المشروع
- `index.php` إعادة توجيه حسب حالة تسجيل الدخول.
- `register.php` إنشاء حساب جديد.
- `login.php` تسجيل الدخول.
- `logout.php` تسجيل الخروج.
- `dashboard.php` لوحة التحكم (إضافة + عرض + فلترة + تحديث + حذف).
- `task_add.php` إضافة مهمة.
- `task_update.php` تحديث حالة مهمة.
- `task_delete.php` حذف مهمة.
- `config/db.php` إعداد اتصال قاعدة البيانات عبر PDO.
- `includes/auth.php` دوال الجلسة، الحماية، ورسائل التنبيه.
- `schema.sql` إنشاء قاعدة البيانات والجداول.

## إعداد سريع
1. أنشئ قاعدة البيانات والجداول:
   - استورد ملف `schema.sql` في MySQL (من phpMyAdmin أو CLI).
2. اضبط بيانات الاتصال بقاعدة البيانات:
   - إما عبر متغيرات البيئة:
     - `DB_HOST`
     - `DB_NAME`
     - `DB_USER`
     - `DB_PASS`
   - أو عدّل القيم الافتراضية مباشرة في `config/db.php`.
3. شغّل التطبيق على خادم PHP:
   ```bash
   php -S localhost:8000
   ```
4. افتح:
   - `http://localhost:8000`

## ملاحظات أمنية مطبقة
- استخدام `password_hash` و `password_verify` لكلمات المرور.
- استخدام Prepared Statements عبر PDO.
- ربط كل عملية على المهام بـ `user_id` للمستخدم الحالي.
- حماية الصفحات الداخلية عبر الجلسات (`$_SESSION`).

## تطوير لاحق مقترح
- تعديل عنوان/وصف المهمة (حاليًا المتاح تحديث الحالة فقط).
- إضافة CSRF token للنماذج.
- إضافة Pagination وبحث.
- تقسيم الواجهة إلى Layout templates.
