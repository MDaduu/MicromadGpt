# خطة عمل تطبيق بسيط بـ PHP + MySQL

هذا مشروع صغير مناسب لك كمطور PHP/MySQL ويمكنك **رفعه على الاستضافة** ومعاينته بسهولة.

## فكرة التطبيق
**تطبيق إدارة مهام (To-Do List)**
- تسجيل مستخدم جديد وتسجيل الدخول.
- إضافة مهمة، تعديلها، حذفها.
- تحديد حالة المهمة: `جديدة` / `قيد التنفيذ` / `مكتملة`.
- فلترة المهام حسب الحالة.

---

## الأدوات
- PHP 8+
- MySQL
- Bootstrap (اختياري للواجهة)
- phpMyAdmin لإدارة قاعدة البيانات
- XAMPP أو Laragon للتجربة محليًا

---

## مراحل التنفيذ

### 1) تجهيز المشروع
- إنشاء مجلد المشروع داخل `htdocs`.
- إنشاء الملفات الأساسية:
  - `index.php`
  - `login.php`
  - `register.php`
  - `dashboard.php`
  - `task_add.php`
  - `task_update.php`
  - `task_delete.php`
  - `config/db.php`

### 2) تصميم قاعدة البيانات
أنشئ قاعدة بيانات باسم `simple_tasks_app` ثم جدولين:

- `users`
  - `id` (PK)
  - `name`
  - `email` (Unique)
  - `password`
  - `created_at`

- `tasks`
  - `id` (PK)
  - `user_id` (FK -> users.id)
  - `title`
  - `description`
  - `status` (new, in_progress, done)
  - `created_at`

### 3) نظام المستخدمين
- صفحة تسجيل حساب جديد مع التحقق من المدخلات.
- تخزين كلمة المرور باستخدام `password_hash`.
- تسجيل الدخول باستخدام `password_verify`.
- استخدام `$_SESSION` لحماية الصفحات الداخلية.

### 4) CRUD للمهام
- إنشاء مهمة جديدة.
- عرض قائمة المهام الخاصة بالمستخدم الحالي فقط.
- تعديل المهمة.
- حذف المهمة.
- تحديث حالة المهمة.

### 5) تحسينات أساسية
- استخدام Prepared Statements للحماية من SQL Injection.
- رسائل نجاح/خطأ واضحة.
- التحقق من الحقول المطلوبة قبل الإرسال.
- تنظيم الأكواد في ملفات منفصلة (اتصال قاعدة البيانات + دوال مساعدة).

---

## خطة زمنية مقترحة (3 أيام)
- **اليوم 1:** إعداد المشروع + قاعدة البيانات + التسجيل/الدخول.
- **اليوم 2:** إضافة وعرض وتعديل وحذف المهام.
- **اليوم 3:** تحسين الواجهة + الحماية + اختبار شامل + الرفع على الاستضافة.

---

## طريقة الرفع والمعاينة

### خيار 1: استضافة مشتركة (cPanel)
1. ارفع ملفات المشروع داخل `public_html`.
2. أنشئ قاعدة البيانات والمستخدم من cPanel.
3. استورد ملف SQL عبر phpMyAdmin.
4. عدّل بيانات الاتصال في `config/db.php`.
5. افتح رابط الموقع وجرب التسجيل والدخول.

### خيار 2: GitHub + Render/Railway (إن دعمت PHP)
1. ارفع المشروع إلى GitHub.
2. اربط المستودع بخدمة الاستضافة.
3. أضف متغيرات البيئة الخاصة بقاعدة البيانات.
4. نفّذ الاستيراد الأولي للجداول.
5. افتح رابط المعاينة (Preview URL).
